# Reference Implementations

These are compact ports of the backend extraction and state rules. They are not full applications and do not include storage, database, OCR, or API code.

- `typescript`: plain TypeScript functions with Vitest golden tests.
- `go`: small package with exported functions and table-driven tests.
- `rust`: small crate with pure functions and unit tests.

The Python backend in `backend/app/services/extraction.py` remains the source of truth.
